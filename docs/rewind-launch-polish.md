the last text reveal. Shared winners retain the existing extra reading allowance.

## Playback contract

All scene flourishes consume the existing chapter MotionValue. No new timers,
repeat loops, per-frame React state, network requests, media downloads, libraries,
or scoring changes. Pause, hidden-tab suspension, seeking, and replay share the
same clock. Reduced motion and paused navigation show complete facts immediately.
Chapter crossfades overlap, with no blank gap. Long and shared names wrap.

Manual personal replay still starts at the player's story. New-season accounts
still receive only official community honors, then return Home. Staff previews
remain available. Personal finale controls remain below the completed story.
